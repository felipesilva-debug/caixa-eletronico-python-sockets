# 💳 Caixa Eletrônico — Python Sockets

Projeto acadêmico desenvolvido em Python com o objetivo de
praticar comunicação entre cliente e servidor utilizando
sockets TCP.

## 📌 Funcionalidades

- Autenticação por matrícula e senha.
- Depósito de valores.
- Saque de valores.
- Consulta de saldo.
- Comunicação entre cliente e servidor em tempo real.

## 🛠️ Tecnologias utilizadas

- Python 3
- Socket Programming
- TCP/IP

## 📂 Estrutura do projeto

caixa-eletronico-python-sockets/
│
├── cliente.py
├── servidor.py
├── README.md
└── LICENSE

## ⚙️ Como executar

### 1. Clone o repositório

git clone https://github.com/SEU-USUARIO/caixa-eletronico-python-sockets.git

### 2. Inicie o servidor

python servidor.py

### 3. Em outro terminal, execute o cliente

python cliente.py
